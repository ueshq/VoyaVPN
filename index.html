App Encryption Documentation
Product: VoyaVPN (macOS)
Bundle ID: app.voyavpn.desktop

1. Summary
VoyaVPN uses encryption solely to protect user network traffic transmitted through VPN and proxy tunnels. The application implements standard encryption algorithms accepted by international standard bodies (IETF, IEEE, ITU, NIST). It does not implement proprietary or non-standard encryption algorithms.

2. Classification
- Encryption type: Standard encryption algorithms (instead of, or in addition to, encryption within Apple's operating system)
- Proprietary encryption: None
- Non-standard algorithms: None
- Apple's requested export compliance choice: "Standard encryption algorithms instead of, or in addition to, using or accessing the encryption within Apple's operating system"

3. Algorithms Implemented
All cryptographic primitives used by the application and its embedded sing-box core are international standards, including:
- TLS 1.2 and TLS 1.3 (IETF RFC 5246, RFC 8446)
- AES-128-GCM and AES-256-GCM (NIST FIPS 197; AEAD per IETF RFC 5116)
- ChaCha20-Poly1305 (IETF RFC 8439)
- X25519 Elliptic Curve Diffie-Hellman (IETF RFC 7748)
- SHA-256 / SHA-384 / SHA-512 (NIST FIPS 180-4)
- HMAC (IETF RFC 2104)

These primitives are combined only through standard VPN/proxy protocol stacks (for example Shadowsocks AEAD, VMess, VLESS/XTLS, Trojan, and TLS-based transports). No custom cipher designs or non-standard cryptographic constructions are introduced.

4. Purpose of Encryption
- Confidentiality and integrity of user network traffic between the client and the user-configured remote endpoint
- Peer authentication and session key establishment for tunnel setup
- Optional local storage protection of user configuration data using platform-provided mechanisms

The encryption is not used for copy protection, DRM, or specialized government/military-only functionality.

5. Availability
- The application is intended for distribution on the Mac App Store in all available territories, including France (subject to the developer's App Store Connect availability settings).
- Encryption documentation can be provided before build submission as requested by App Review.

6. Declaration
We declare that VoyaVPN uses only standard encryption algorithms as listed above, and does not contain proprietary encryption that would require additional classification beyond standard-algorithm disclosure.
